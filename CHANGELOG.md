# Changelog V4.0.0

- Now available for **Fabric, Quilt, NeoForge and Forge** — previously Fabric only.
- Supports **Minecraft 1.20 through 1.21.11** from a single codebase.
- Fixed the mod list crashing on NeoForge when selecting Armor HUD.
- Fixed durability bars drawing behind the armour icons on 1.21.5 and earlier.
- Fixed the settings screen header not showing on newer versions.
- Settings screen text is now translatable.
